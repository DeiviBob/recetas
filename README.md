# Recetas

Plataforma de recetas: un backend modular (Go) y tres apps (web, Apple y Android, en Flutter) que hablan con él solo a través de un contrato (OpenAPI 3.1 escrito en TypeSpec).

- Reglas para trabajar: [`CLAUDE.md`](CLAUDE.md).
- Decisiones y plan: [`docs/`](docs) (`ANALISIS.md`, `DECISIONES.md`, `MAPA.md`).
- Todo entra a `main` por pull request con la CI en verde.
